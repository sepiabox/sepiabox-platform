## S-035 — Serve the app at app.sepiabox.com
**Epic:** Cloud and costs
**Depends on:** S-032
**Priority:** Low
**Size:** S

### Context
The Google login shows the domain; `app.sepiabox.com` inspires more trust than the address generated by Azure.

### Scope
- `customDomain` parameter in the AppHost: custom domain + managed certificate on the web Container App when set.
- HSTS header in production.
- `docs/operations.md`: exact DNS records (CNAME `app` → app FQDN; TXT `asuid.app` → verification id) and OAuth redirect URIs.

### Out of scope
- Creating the DNS records (human step at GoDaddy).

### Acceptance criteria
- [ ] Given `customDomain` set, then the generated Bicep has the domain and the managed certificate.
- [ ] Given `customDomain` empty, then the Bicep has no custom domain.
- [ ] Given a request in production, then the response has the `Strict-Transport-Security` header.

### Technical notes
- Human step: DNS at GoDaddy.

### Expected tests
- Infrastructure generation test; HSTS middleware test.
